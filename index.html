O que é uma Função Callback?

Em JavaScript, funções são cidadãs de primeira classe. Isso significa que você pode tratar uma função como qualquer outro valor: pode guardá-la em uma variável e, o mais importante, passar uma função como parâmetro para outra função!

💡

Definição Simples: Callback (literalmente "chamar de volta") é uma função que é passada a outra função com a instrução: "Guarde esta função e execute-a mais tarde, quando terminar certa tarefa".

🍕 Analogias do Mundo Real

🍕

1. O Pedido de Pizza

Imagine que você liga para a pizzaria. Você faz o pedido e deixa seu número de telefone (seu callback).

  • ✓ Pedido enviado ➜ A pizzaria assa a pizza
  • ✓ Pizza fica pronta ➜ A pizzaria liga de volta (Callback!)
  • ✓ Você atende e come a pizza
⏰

2. O Despertador de Tarefas

Você programa o alarme do celular para tocar às 07:00 com uma instrução: "Tocar a música do Rocky Balboa".

  • ✓ O tempo passa... (Processamento em segundo plano)
  • ✓ Chega 07:00 ➜ O alarme aciona a música (Callback)
  • ✓ Você acorda motivado!

⚙️ A Sintaxe Básica no JavaScript

Observe a diferença entre definir uma função callback, passar a função como parâmetro e receber/executar ela.

Código Exemplo: 
function saudar(nome) {
  console.log(`Olá, ${nome}!`);
}

function processarUsuario(callback) {
  const nome = "Maria";
  // Executando o callback recebido:
  callback(nome); 
}

// Passamos saudar SEM os parênteses ()
processarUsuario(saudar);
⚠️ Erro muito comum de iniciantes!

Nunca passe o callback executando-o com parênteses saudar() ao passar como parâmetro!

❌ processarUsuario(saudar()); // Errado! Executa imediatamente.
✅ processarUsuario(saudar); // Certo! Passa a função como receita.

📚 Onde os Callbacks São Usados no Dia a Dia? (9 Exemplos Práticos)

Você usará callbacks a todo momento em projetos reais de JavaScript. Veja os casos mais comuns:

1. Escutar Eventos (DOM) Eventos

A função só é executada quando o usuário clica no botão.

const botao = document.querySelector('#btn');

botao.addEventListener('click', function() {
  console.log('Clicou!');
});
2. Mapear e Filtrar Listas Arrays

Passamos um callback para dizer como filtrar os itens.

const notas = [4, 7, 9, 2, 10];

const aprovados = notas.filter(n => n >= 7);
console.log(aprovados); // [7, 9, 10]
3. Temporizadores Timer

Executa o callback repetidamente a cada intervalo.

let sec = 0;
setInterval(() => {
  sec++;
  console.log(`Tempo: ${sec}s`);
}, 1000);
4. Callbacks de Resultado Lógica

Um callback para sucesso e outro para tratar falha.

function login(usr, onOk, onErr) {
  usr === "admin" ? onOk() : onErr();
}
5. Encontrar Elemento (.find) Busca

Callback testa cada item até achar o primeiro correspondente.

const users = [{id: 1}, {id: 2}];
const user = users.find(u => u.id === 2);
console.log(user); // {id: 2}
6. Ordenação Customizada (.sort) Array

O callback compara dois itens para definir a ordem crescente/decrescente.

const nums = [40, 100, 1, 5];
nums.sort((a, b) => a - b);
console.log(nums); // [1, 5, 40, 100]
7. Acumular Valores (.reduce) Soma

Soma ou combina itens de uma lista em um valor final.

const valores = [10, 20, 30];
const total = valores.reduce((acc, val) => acc + val, 0);
console.log(total); // 60
8. Validação de Lista (.some / .every) Checagem

Verifica se algum ou todos os elementos atendem uma regra.

const idades = [18, 22, 15];
const temMenor = idades.some(id => id < 18);
console.log(temMenor); // true
9. Substituição de Texto Customizada String

Aplica lógica customizada para cada trecho substituído.

const texto = "olá mundo javascript";
const formatado = texto.replace(/\b\w/g, char => char.toUpperCase());
console.log(formatado); // "Olá Mundo Javascript"
